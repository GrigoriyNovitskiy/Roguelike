## Требования

- Python 3.8 или выше
- Pygame для отрисовки управления зависимостями

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/Roguelike.git
cd Roguelike
```

2. Установите зависимости:
```bash
pip install pygame
```

## Запуск

```bash
bash python main.py
```

## Управление

- `h/j/k/l` - движение влево/вниз/вверх/вправо
- `y/u/b/n` - движение по диагонали
- `g` - поднять предмет
- `i` - открыть инвентарь
- `q` - выйти из игры

## Разработка

Игра разработана с использованием следующих технологий и библиотек:

- Python 3.8+
- Pygame для управления зависимостями и отрисовки
- numpy для работы с массивами
